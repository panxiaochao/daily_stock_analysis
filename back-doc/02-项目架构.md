## 模块职责

| 模块 | 路径 | 职责 |
|------|------|------|
| **core/pipeline** | `src/core/pipeline.py` | 核心分析流水线，协调各模块完成股票分析 |
| **core/market_review** | `src/core/market_review.py` | 大盘复盘分析 |
| **core/trading_calendar** | `src/core/trading_calendar.py` | A股/港股/美股交易日历管理 |
| **data_provider/** | `data_provider/*.py` | 多数据源适配与 failover |
| **services/analyzer** | `src/analyzer.py` | LLM 调用和报告生成 |
| **services/notification** | `src/notification.py` | 通知渠道管理 |
| **agent/** | `src/agent/*.py` | Agent 策略问股系统 |
| **bot/** | `bot/*.py` | 平台机器人集成 |
| **api/** | `api/*.py` | FastAPI REST API |

## 数据流

```
股票代码 → DataFetcherManager → 多数据源并行获取 → 数据标准化
                                       │
                                       ▼
                              技术指标计算 (TA-Lib/自实现)
                                       │
                    ┌──────────────────┼──────────────────┐
                    ▼                  ▼                  ▼
              SearchService      StockAnalyzer      筹码分析
              (新闻/舆情)        (趋势/形态)        (ChipDistribution)
                    │                  │                  │
                    └──────────────────┼──────────────────┘
                                       │
                                       ▼
                              GeminiAnalyzer (LLM)
                              整合所有信息生成报告
                                       │
                    ┌──────────────────┴──────────────────┐
                    ▼                                     ▼
             NotificationService                   DatabaseManager
             (推送通知)                              (存储结果)
```
