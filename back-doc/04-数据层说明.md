# 04-数据层说明

## data_provider/ - 多数据源适配层

### 设计模式

采用**策略模式 + 链式 Failover**：
1. 多个数据源按优先级排序
2. 优先使用高优先级数据源
3. 失败时自动切换到下一个数据源
4. 记录各数据源的调用结果用于优化

### 数据源优先级

**配置了 TUSHARE_TOKEN 时**：
1. TushareFetcher (Priority 0) - 最高优先级
2. EfinanceFetcher (Priority 0) - 同优先级
3. AkshareFetcher (Priority 1)
4. PytdxFetcher (Priority 2)
5. BaostockFetcher (Priority 3)
6. YfinanceFetcher (Priority 4)

**未配置 TUSHARE_TOKEN 时**：
1. EfinanceFetcher (Priority 0) - 最高优先级
2. AkshareFetcher (Priority 1)
3. PytdxFetcher (Priority 2)
4. TushareFetcher (Priority 2) - 不可用
5. BaostockFetcher (Priority 3)
6. YfinanceFetcher (Priority 4)
7. LongbridgeFetcher (Priority 5) - 美股/港股兜底

### Fetcher 类

| Fetcher | 市场 | 特点 |
|---------|------|------|
| EfinanceFetcher | A股 | 东方财富数据，Priority 0 |
| AkshareFetcher | A股 | akshare 库，行情全面 |
| TushareFetcher | A股 | Tushare Pro API，需 token |
| PytdxFetcher | A股 | 通达信行情，本地服务器 |
| BaostockFetcher | A股 | 证券宝，午休数据不稳定 |
| YfinanceFetcher | 港股/美股 | Yahoo Finance |
| LongbridgeFetcher | 港股/美股 | 长桥 OpenAPI |
| TickflowFetcher | A股/港股 | TickFlow 官方 SDK |

## src/storage.py - 数据存储

**数据库**：SQLite（Python 内置）

**核心类**：`DatabaseManager`

**主要表**：
- `analysis_reports` - 分析报告
- `llm_usage` - LLM 使用记录
- `backtest_results` - 回测结果
- `system_config` - 系统配置（WebUI 配置存储）

**位置**：可通过 `config.db_path` 配置
