### 平台集成

| 平台 | 文件 | 模式 | 配置项 |
|------|------|------|--------|
| 钉钉 | `dingtalk.py` / `dingtalk_stream.py` | Webhook / Stream | `DINGTALK_SECRET`, `DINGTALK_WEBHOOK` |
| 飞书 | `feishu.py` / `feishu_stream.py` | Webhook / Stream | `FEISHU_SECRET`, `FEISHU_WEBHOOK` |
| Discord | `discord.py` | Bot | `DISCORD_BOT_TOKEN` |

### Stream 模式

Stream 模式相比 Webhook 模式的优点：
- 长连接，无需配置公网回调
- 更安全
- 支持更多互动能力

**启动**（在 `main.py` 中）：
```python
if config.dingtalk_stream_enabled:
    from bot.platforms import start_dingtalk_stream_background
    start_dingtalk_stream_background()

if config.feishu_stream_enabled:
    from bot.platforms import start_feishu_stream_background
    start_feishu_stream_background()
```

### 命令系统

#### CommandDispatcher

核心分发器，将消息路由到对应命令。

```python
class CommandDispatcher:
    def dispatch(self, message: BotMessage) -> Optional[str]:
        # 解析命令前缀和参数
        # 路由到对应命令处理器
```

### BotMessage 模型

```python
@dataclass
class BotMessage:
    platform: str              # 平台标识
    user_id: str               # 用户 ID
    content: str               # 消息内容
    raw: Dict[str, Any]        # 原始消息
    # ...
```

### 通知 vs 机器人

**通知渠道**（被动接收）：
- 配置 Webhook URL
- 单向推送消息
- 用于每日分析报告推送

**机器人平台**（主动交互）：
- 配置 Bot Token
- 支持命令交互
- 用于实时查询和控制
