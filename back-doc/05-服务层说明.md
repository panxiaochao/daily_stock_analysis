# 05-服务层说明

## LLM 分析服务 (src/analyzer.py)

### GeminiAnalyzer

核心分析类，封装 LiteLLM 调用逻辑。

**配置**：
- 支持模型：Anthropic、Gemini、OpenAI、DeepSeek、Ollama 等
- 通过 `litellm.Router` 实现负载均衡和 failover
- 支持 thinking/non-thinking 模式

**主要方法**：
```python
class GeminiAnalyzer:
    def analyze_stock(self, code, data, search_result, ...) -> AnalysisResult
    def generate_report(self, stock_info, technical, news, ...) -> str
    def parse_llm_response(self, raw_response) -> AnalysisResult
```

**AnalysisResult 结构**：
```python
@dataclass
class AnalysisResult:
    code: str
    name: str
    sentiment_score: int          # 情绪评分 0-100
    operation_advice: str         # 操作建议
    trend_prediction: str         # 趋势预测
    risk_warning: List[str]       # 风险预警
    bullish_factors: List[str]    # 利好催化
    key_levels: KeyLevels         # 关键点位
    check_list: List[str]         # 操作检查清单
    # ...
```

## 通知服务 (src/notification.py)

### NotificationService

多渠道通知管理。

**支持渠道**：

| 渠道 | 配置项 |
|------|--------|
| 企业微信 | `WECHAT_WEBHOOK_URL` |
| 飞书 | `FEISHU_WEBHOOK_URL` |
| Telegram | `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` |
| Discord | `DISCORD_WEBHOOK_URL` |
| Slack | `SLACK_BOT_TOKEN` + `SLACK_CHANNEL_ID` |
| 邮件 | `EMAIL_SENDER` + `EMAIL_PASSWORD` |

**通知模式**：
- 合并推送（默认）：所有股票汇总后一次推送
- 单股推送：`--single-notify` 或 `SINGLE_STOCK_NOTIFY=true`

**Report Type**：
- `simple`：决策仪表盘（简洁）
- `detailed`：详细分析报告
- `markdown`：完整 Markdown

**图片生成**：
- 使用 `imgkit` + `wkhtmltopdf` 将 Markdown 转为图片
- 配置项：`MARKDOWN_TO_IMAGE_ENABLED`

## 搜索服务 (src/search_service.py)

### SearchService

新闻和舆情检索，支持多源 failover。

**支持搜索源**：

| 搜索源 | 配置项 | 特点 |
|--------|--------|------|
| Anspire | `ANSPIRE_API_KEYS` | 中文优化，含 AI 摘要 |
| SerpAPI | `SERPAPI_API_KEYS` | 搜索引擎结果 |
| Tavily | `TAVILY_API_KEYS` | 通用新闻 |
| Bocha | `BOCHA_API_KEYS` | 中文搜索优化 |
| Brave | `BRAVE_API_KEYS` | 隐私优先 |
| MiniMax | `MINIMAX_API_KEYS` | 结构化结果 |
| SearXNG | `SEARXNG_BASE_URLS` | 自建实例 |

**搜索策略**：
- 按股票代码和名称组合搜索
- 支持时间窗口配置（`ultra_short`/1天, `short`/3天, `medium`/7天, `long`/30天）
- 自动重试和 failover

## 回测服务 (src/services/backtest_service.py)

### BacktestService

对历史分析结果进行评估。

**配置**：
- `BACKTEST_ENABLED` - 是否启用自动回测
- `BACKTEST_EVAL_WINDOW_DAYS` - 评估窗口（默认 10 交易日）
- `BACKTEST_MIN_AGE_DAYS` - 最小历史天数（默认 14 天）
