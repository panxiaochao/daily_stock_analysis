# 07-前端应用说明

## apps/dsa-web/ - React Web 应用

### 技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **路由**：React Router
- **状态管理**：React Context / Zustand（待确认）
- **UI 组件**：shadcn/ui
- **样式**：Tailwind CSS

### 目录结构

```
apps/dsa-web/
├── public/
│   └── stocks.index.json     # 股票指数数据
├── src/
│   ├── components/           # React 组件
│   │   ├── ui/              # shadcn/ui 组件
│   │   └── ...
│   ├── pages/               # 页面组件
│   ├── hooks/               # 自定义 Hooks
│   ├── services/            # API 调用
│   ├── stores/              # 状态管理
│   ├── types/               # TypeScript 类型
│   ├── utils/               # 工具函数
│   ├── App.tsx
│   └── main.tsx
├── package.json
├── tsconfig.json
├── vite.config.ts
└── index.html
```

### 主要页面

| 页面 | 路由 | 说明 |
|------|------|------|
| 工作台 | `/` | 首页概览 |
| 分析 | `/analyze` | 手动分析 |
| 历史报告 | `/history` | 历史分析列表 |
| 报告详情 | `/history/:id` | 完整 Markdown 报告 |
| Agent 问股 | `/chat` | 策略问股 |
| 持仓管理 | `/portfolio` | 持仓导入与管理 |
| 回测 | `/backtest` | 回测界面 |
| 配置 | `/settings` | 系统配置 |
| 登录 | `/login` | 认证 |

### 构建命令

```bash
cd apps/dsa-web
npm ci                    # 安装依赖
npm run lint             # ESLint 检查
npm run build            # 生产构建
npm run preview          # 预览构建结果
```

### 环境变量

```bash
VITE_API_BASE_URL=http://localhost:8000
```

### 前端资源

构建产物默认输出到 `apps/dsa-web/dist/`，由 FastAPI 在生产模式下托管。

**注意**：GitHub #1064/#1065/#1050 相关的资源一致性检查：
- `api/app.py` 中的 `_check_frontend_assets_consistency()` 会在启动时验证 `index.html` 引用的资源是否存在
- 资源不匹配会导致桌面端白屏

- 通知渠道配置

- 浅色/深色主题切换
