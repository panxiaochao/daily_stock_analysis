# 11-测试说明

## 测试框架

- **框架**：pytest
- **标记**：`@pytest.mark.network` - 网络相关测试

## 测试命令

```bash
# 运行所有测试
python -m pytest

# 运行非网络测试（CI 默认）
python -m pytest -m "not network"

# 运行特定测试
python -m pytest tests/test_config.py

# 运行带 coverage
python -m pytest --cov=src tests/
```

## CI 测试流程

CI gate 执行顺序：

```bash
./scripts/ci_gate.sh all

# 等价于：
./scripts/ci_gate.sh syntax    # Python 语法检查
./scripts/ci_gate.sh flake8    # Flake8 检查
./scripts/ci_gate.sh deterministic  # 本地确定性测试
./scripts/ci_gate.sh offline-tests # 离线测试套件
```

### Syntax Check

```bash
python -m py_compile main.py src/config.py src/auth.py src/analyzer.py src/notification.py
python -m py_compile src/storage.py src/scheduler.py src/search_service.py
python -m py_compile src/market_analyzer.py src/stock_analyzer.py
python -m py_compile data_provider/*.py
```

### Flake8

```bash
flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics
```

仅检查严重错误：E9（语法/导入错误）、F63（类型检查错误）、F7（语法错误）、F82（未定义变量）

### Deterministic Tests

```bash
./scripts/test.sh code
./scripts/test.sh yfinance
```

### Offline Tests

```bash
python -m pytest -m "not network"
```

## 测试覆盖原则

| 测试类型 | 网络依赖 | CI 状态 |
|----------|----------|---------|
| 单元测试 | 无 | 必跑 |
| 集成测试 | 部分 | 必跑（离线） |
| 网络测试 | 是 | 仅本地/可选 |

## 特定测试标记

```python
@pytest.mark.network  # 标记为网络测试，本地执行
@pytest.mark.skip_if_ci  # CI 环境跳过
```
