# 03-核心模块说明

## src/core/ - 核心编排层

### pipeline.py - 分析流水线

**职责**：管理整个股票分析流程，协调数据获取、存储、搜索、分析、通知等模块。

**核心类**：`StockAnalysisPipeline`

**主要方法**：
- `run(stock_codes, dry_run, send_notification, merge_notification)` - 执行分析
- `_fetch_stock_data(code)` - 获取单只股票数据
- `_analyze_stock(data, search_result)` - 分析单只股票
- `_send_notification(results)` - 发送通知

**并发控制**：使用 `ThreadPoolExecutor` 实现低并发调度，默认 `max_workers=3`

**异常处理**：单股失败不影响整体流程，使用 try-except 隔离

### market_review.py - 大盘复盘

**职责**：生成大盘每日复盘报告，包括指数涨跌、板块表现、市场概况等。

**核心函数**：`run_market_review(notifier, analyzer, search_service, send_notification, override_region)`

**支持市场**：上证、深证、创业板、科创板、港股、美股

### trading_calendar.py - 交易日历

**职责**：判断今日是否为交易日，过滤非交易日股票。

**核心函数**：
- `get_open_markets_today()` - 获取今日开市的市场
- `get_market_for_stock(code)` - 获取股票所属市场
- `is_market_open(market)` - 判断市场是否开市

**注意**：Issue #373 引入了交易日检查，配置 `TRADING_DAY_CHECK_ENABLED=false` 可跳过

### market_review_lock.py - 大盘复盘锁

**职责**：防止并发执行大盘复盘，确保同一时刻只有一个大盘复盘任务运行。

**实现**：使用文件锁（`fcntl.flock`）

### market_profile.py - 市场轮廓

**职责**：市场多维度数据聚合

### market_strategy.py - 市场策略

**职责**：市场策略配置与管理

### backtest_engine.py - 回测引擎

**职责**：对历史分析结果进行评估，计算收益率、夏普比率等指标。

### config_manager.py - 配置管理器

**职责**：读写 `.env` 配置文件，支持热更新。

**Agent 类型**：

| Agent | 职责 |
|-------|------|
| DecisionAgent | 决策建议 |
| TechnicalAgent | 技术分析 |
| PortfolioAgent | 持仓管理 |
| RiskAgent | 风险管理 |
| IntelAgent | 情报收集 |

**内置策略**（11种）：均线金叉、缠论、波浪理论、多头趋势等
