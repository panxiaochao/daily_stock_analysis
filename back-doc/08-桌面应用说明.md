# 08-桌面应用说明

## apps/dsa-desktop/ - Electron 桌面应用

### 技术栈

- **框架**：Electron
- **前端**：复用 `apps/dsa-web` 构建产物
- **打包**：electron-builder
- **平台**：macOS / Windows / Linux

### 目录结构

```
apps/dsa-desktop/
├── src/
│   ├── main/               # Electron 主进程
│   │   ├── index.ts
│   │   ├── preload.ts
│   │   └── ...
│   └── renderer/          # 渲染进程（复用 Web）
├── scripts/               # 打包脚本
├── package.json
└── electron-builder.yml
```

### 构建命令

```bash
cd apps/dsa-desktop
npm install                # 安装依赖
npm run build              # 构建桌面应用
```

本地构建脚本：
- `scripts/build-desktop-macos.sh` - macOS 构建
- `scripts/build-backend-macos.sh` - 后端构建
- `scripts/build-all-macos.sh` - 全量构建

### 打包配置

```yaml
# electron-builder.yml
appId: com.daily-stock-analysis.desktop
productName: DSA Desktop
directories:
  output: dist
  buildResources: build
files:
  - dist/**/*
  - build/**/*
mac:
  category: public.app-category.finance
  target: dmg
win:
  target: nsis
linux:
  target: AppImage
```

### 特性

- 桌面端独立窗口
- 系统托盘运行
- 原生通知
- 自动更新（待确认）

### 已知问题

**资源一致性**：
- Issue #1064/#1065/#1050：桌面端白屏问题
- 原因：`index.html` 引用的资源在打包后不存在
- 解决：重新构建前端，确保 `static/` 目录正确复制

**macOS 安全**：
- 需要签名和公证才能正常运行
- 开发时可使用 `npm run dev` 绕过

### 与 Web 的关系

1. 桌面应用使用与 Web 相同的 React 前端代码
2. 后端 API 通过 `localhost:8000` 访问
3. 桌面应用启动时自动启动后端服务（待确认）
