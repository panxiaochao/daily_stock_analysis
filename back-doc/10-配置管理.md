# 10-配置管理

## 环境配置

### .env 文件

项目根目录的 `.env` 文件存储所有配置（不提交到 Git）。

**模板**：`.env.example`

### 配置加载流程

```
.env 文件
    │
    ▼
dotenv_values() 读取
    │
    ▼
setup_env() 处理
    │
    ▼
Config 单例类
    │
    ▼
各模块通过 get_config() 访问
```

## Config 类 (src/config.py)

**模式**：单例模式

```python
class Config:
    _instance = None

    @classmethod
    def get_instance(cls) -> Config:
        if cls._instance is None:
            cls._instance = cls()
        return cls._instance

    @classmethod
    def reset_instance(cls):
        cls._instance = None
```

**配置验证**：`config.validate()` 返回 `List[ConfigIssue]`

**热更新**：WebUI 修改配置后，通过 `ConfigManager` 写回 `.env`，主进程通过 `SCHEDULE_TIME` 等配置的热更新机制感知变化。
